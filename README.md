# Fashion Exchange — локальный MVP

Рабочее приложение для учёта товаров: React + TypeScript, Express на Node.js 24 и SQLite. Английский интерфейс, светлая панель в стиле предоставленного референса.

## Открыть и запустить

Если сервер запущен: http://127.0.0.1:3007

Из папки проекта:

```sh
npm start
```

После изменения интерфейса:

```sh
npm run build
npm start
```

При переносе проекта на другой компьютер нужны Node.js 24+ и однократная установка зависимостей `npm ci`. После установки локальный запуск не требует интернета. Не закрывайте терминал с сервером во время работы; остановка — Ctrl+C. Сервер слушает только 127.0.0.1.

## Тестовые аккаунты

Начальный администратор создаётся автоматически по требованиям Sprint 1:

- Логин: `Admin`
- Временный пароль при первой инициализации: `Welcome!` — **он уже был изменён и больше не работает в текущей базе**.

При первом входе администратор может открыть только Profile settings и обязан установить собственный пароль длиной не менее 12 символов. Остальные демонстрационные логины указаны в `data/demo-accounts.txt`. После административного сброса пароль Арсения находится в отдельном файле `data/arseniy-login-2026-09-27.txt`. Не публикуйте эти файлы, папку data или резервные копии.

- Администратор: Admin — все товары, назначения, отправки и управление пользователями.
- Сотрудник: arseniy@fashionexchange.local — просмотр каталога, ручное создание, назначение свободных товаров себе и изменение своих товаров.
- Отправитель: shipping@fashionexchange.local — каталог только для чтения, очередь отправки и свой профиль.

Права проверяет сервер. Сессия завершается после 120 минут бездействия. Приостановка пользователя сразу отзывает его активные сессии. Смена или административный сброс пароля также завершает прежние сессии пользователя.

## Что можно показать владельцу

1. Overview — показатели, новые записи и журнал с раскрываемыми подробностями изменений.
2. All items — поиск по названию, внутреннему номеру и ID eBay; фильтры владельца и наличия ID; страницы по десять строк.
3. Add item — название, цена USD, количество, eBay ID, место хранения, ответственный и заметка.
4. Карточка — редактирование, архивирование и восстановление. Товар незавершённой отправки нельзя архивировать.
5. My items — свой список. Assign to me — атомарное назначение свободной записи.
6. Export — CSV текущей выборки с защитой текстовых ячеек от формул.
7. Shipping — пять вымышленных заказов: To pack → Packed → Shipped. При отправке требуется трек-номер; сохраняются сотрудник, время и номер. Действия не отправляют данные на торговые площадки.
8. User administration — единая таблица пользователей; администратор создаёт логины, назначает роли, сбрасывает временные пароли и приостанавливает аккаунты без удаления истории. Для Suspend нужно удерживать кнопку одну секунду и подтвердить действие; приостановленный аккаунт можно снова активировать.
9. Profile settings — смена пароля с обязательным вводом текущего пароля и подтверждением нового.

Цена хранится целыми центами. Ручное сохранение имеет ключ повторного запроса: повтор одного сохранения не создаёт вторую запись. Конфликт версии не позволяет незаметно перезаписать чужое изменение. Уникальный eBay ID проверяется самой базой.

## База и резервные копии

Рабочая база: `data/fashionexchange.sqlite`. При работающем сервере рядом могут быть файлы `-wal` и `-shm`; не копируйте только основной файл вручную. Команда ниже создаёт согласованный снимок и проверяет целостность:

```sh
npm run backup
```

Выбрать имя копии:

```sh
npm run backup -- backups/before-demo.sqlite
```

Восстановить **в новый отдельный файл**, не затирая рабочие данные:

```sh
npm run restore -- backups/before-demo.sqlite data/restored.sqlite
```

После остановки основного сервера проверить восстановленную базу:

```sh
FX_DB=data/restored.sqlite npm start
```

Восстановление проверяет структуру, целостность и внешние ключи. Сессии в восстановленном файле очищаются — войдите заново. Пароли берутся из копии. Существующий целевой файл не перезаписывается. Копии содержат данные и хеши паролей; храните их отдельно и не публикуйте. Планировщик автоматических копий пока не установлен.

Тесты используют временную базу и отдельный локальный порт 3107, не изменяют рабочие записи. Подробности: `VERIFICATION.md`.

## Границы этой версии

- Это локальный MVP, не публичный сервис. Компьютер должен быть включён, сервер запущен.
- eBay не подключён: ID — только ссылка-идентификатор. Нет импорта, публикации, синхронизации заказов, автоматического распознавания инициалов или снятия объявлений.
- Vendoo, Mercari и Poshmark не подключены. Старую MySQL/MariaDB не импортировали.
- Заказы и получатели вымышленные. Отметка Shipped не покупает этикетку, не уведомляет покупателя и не уменьшает физический остаток. Реальное резервирование и списание единиц — будущий этап вместе с интеграцией заказов.
- У товаров — иллюстративные значки категорий. Загрузка фотографий не входит в этот этап.
- Старые «5%» и «GTC 2 Month» не используются в расчётах до объяснения владельцем.
- Показанные сумма и цена не означают прибыль, комиссию или начисленную сотруднику оплату.
- Регистрация и восстановление пароля по email намеренно отсутствуют. Новые аккаунты и временные пароли создаёт администратор; существующие записи не удаляются.
- Перед рабочими бизнес-данными и внешним доступом необходимы отдельные проверки безопасности, хостинга, восстановления и миграции. Локальная HTTP-cookie рассчитана только на loopback; для внешнего запуска нужен HTTPS и пересмотр конфигурации.

## Структура проекта

- `src/main.tsx`, `src/styles.css`: интерфейс и стили.
- `server/index.mjs`: HTTP API, сессии, права и операции.
- `server/db.mjs`: схема, начальные записи, транзакции и аудит.
- `scripts/database.mjs`: создание и восстановление копий.
- `tests/api.test.mjs`: интеграционные проверки.
- `php-backend`: параллельная PHP/MySQL-реализация основы авторизации Sprint 1; пока не является запущенным локальным сервером.
- `package-lock.json`: зафиксированные зависимости.

В production-доступ не входят npm dev-server, база, тексты аккаунтов и резервные копии: Express отдаёт только собранную папку dist и авторизованный API.
